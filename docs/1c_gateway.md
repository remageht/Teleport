# Пример HTTP-сервиса 1С (УТ 11 / УНФ / ERP)

Модуль внешней обработки, публикуемой как HTTP-сервис `radiotrade` в конфигурации 1С.

## Обработчик `/push`, метод POST

```bsl
Функция ОбработкаЗапроса(Запрос)
    Тело = Запрос.ПолучитьТелоКакСтроку();
    Данные = ПрочитатьJSON(Тело);

    Принято = Новый Массив;

    Для Каждого Элемент Из Данные.items Цикл
        Если Элемент.entity = "order" Тогда
            Документ = Документы.ЗаказКлиента.СоздатьДокумент();
            Документ.Дата        = ТекущаяДатаСеанса();
            Документ.Контрагент  = Справочники.Контрагенты.НайтиПоУИД(Элемент.data.client_id);
            Документ.Склад       = Справочники.Склады.НайтиПоУИД(Элемент.data.warehouse_id);
            Документ.Менеджер    = Справочники.Пользователи.НайтиПоУИД(Элемент.data.agent_id);
            Документ.СуммаДокумента = Элемент.data.total;
            Для Каждого Строка Из Элемент.data.lines Цикл
                Номенклатура = Справочники.Номенклатура.НайтиПоУИД(Строка.product_id);
                ТЧ = Документ.Товары.Добавить();
                ТЧ.Номенклатура = Номенклатура;
                ТЧ.Количество   = Строка.qty;
                ТЧ.Цена         = Строка.price;
                ТЧ.СкидкаPercent= Строка.discount_pct;
            КонецЦикла;
            Документ.Записать(РежимЗаписиДокумента.Проведение);
            Принято.Добавить(Элемент.local_id);
        ИначеЕсли Элемент.entity = "stock_count" Тогда
            // Инвентаризация: документ "Списание недостач товаров" или "Инвентаризация"
            Принято.Добавить(Элемент.local_id);
        ИначеЕсли Элемент.entity = "photo_report" Тогда
            // Сохранить фото в присоединённые файлы клиента
            Принято.Добавить(Элемент.local_id);
        КонецЕсли;
    КонецЦикла;

    // Вернуть подтверждение + свежие остатки мобильного склада
    Остатки = ПолучитьОстаткиМобильногоСклада();
    Ответ = Новый Структура("accepted", Принято);
    Ответ.Вставить("stocks", Остатки);
    Возврат ЗаписатьJSON(Ответ);
КонецФункции
```

## Обработчик `/pull`, метод GET

```bsl
Функция ОбработкаЗапроса(Запрос)
    // Вернуть изменённые с курсора номенклатуру/клиентов/остатки
    // SELECT * FROM Справочник.Номенклатура ГДЕ Изменён > Курсор
    Ответ = Новый Структура;
    Ответ.Вставить("products", ТоварыПоКурсору(Запрос.ПолучитьПараметр("cursor_products")));
    Ответ.Вставить("clients",   КлиентыПоКурсору(Запрос.ПолучитьПараметр("cursor_clients")));
    Ответ.Вставить("stocks",    ОстаткиПоКурсору(Запрос.ПолучитьПараметр("cursor_stocks")));
    Возврат ЗаписатьJSON(Ответ);
КонецФункции
```

## Публикация
1. Конфигуратор → HTTP-сервисы → добавить сервис `radiotrade` (корневой URL `rs`).
2. Опубликовать на веб-сервере (IIS/Apache) с HTTPS.
3. Если 1С за NAT — ретранслировать через облако (nginx reverse proxy).
4. Адрес шлюза указывается в настройках приложения (Настройки → Адрес шлюза 1С).

Формат цены: `"price": 12.50` (рубли, две десятичные). Все идентификаторы — GUID 1С.
